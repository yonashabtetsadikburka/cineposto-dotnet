# Glossary
| Term | Meaning |
|---|---|
| Cinema | A movie theater in Umbria, identified by a unique slug |
| Film | A movie, possibly shown in several cinemas |
| Showing | A film's screening at a cinema on a date, with a list of times |
| Connector | The component that fetches data from one cinema source |
| Scrape run | One execution of the scraper, with its results and errors |
