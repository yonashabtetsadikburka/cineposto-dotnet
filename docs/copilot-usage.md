# How I use AI in this project

## Tools
OpenCode, GitHub Copilot.

## Personal rules
- I always understand and can explain generated code before committing it.
- Every output is verified with a build, a test, or a line-by-line read.
- I never paste secrets or tokens into prompts.
- Expected values in parity tests come from files generated by the legacy code, never typed by hand.

## Cases where the AI was wrong
| Date | Tool | What went wrong | How I noticed | How I fixed it |
|---|---|---|---|---|
| 2026-10-09 | OpenCode | A hand-transcribed expected value in the parity tests contained a typo | One parity test failed while the C# output was correct | Compared with the legacy-generated TSV, fixed the value, and now generate test data from the TSV |
